The simple project is based on a free Angular 18 template named Core.UI

Candidates need to prepare development environment first:
1.	Git https://git-scm.com/downloads (for download and upload codes)
2.	Node.js https://nodejs.org/en version>=18.19
3.	VS Code https://code.visualstudio.com/ (You can also choose your preferred front-end development tools for this interview, for example WebStorm, etc.)
